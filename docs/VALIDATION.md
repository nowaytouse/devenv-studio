## 实际边界

- 恢复记录需要同一用户的 `recovery.key` 及程序内受信任的对应清单版本；0.2内置了首版快照。不要只复制或删掉恢复密钥；升级前保留对应程序和数据目录。
- 注册表冲突检查在写入前以及日志落盘后进行；本程序实例通过文件锁串行执行。其他软件仍可能在最终原生调用的短暂间隔并发写入，因此不宣称跨进程原子比较写入。
- 组织策略可以覆盖用户偏好。注册表回读一致不等于已验证系统 UI 效果。
- 原来不存在的注册表值恢复时删除，新建的空键可能保留。
- 导出通过硬链接完成不覆盖式发布，要求目标文件系统支持硬链接。APFS/NTFS 等可用；不支持硬链接的文件系统会返回错误，可先导出到本地再复制。
- 当前已增加软件安装、开发工具、功能、维护与5组AC电源参数；驱动、Store/WinGet自动引导、网络和原工具其余能力仍在 ROADMAP 中。
