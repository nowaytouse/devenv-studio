# 后续集成路线

本文件记录尚未交付的能力。未实现项目不会出现在 GUI 中冒充可用开关。

1. **Windows LTSC 验收**：分别在 2021/2024 的干净虚拟机测试用户权限、应用、退出、取消、故障中断与恢复，核对每个设置在系统界面的实际效果；保存脱敏证据。
2. **迁移原工具的软件配置能力**：提取 LTSC_Tools_Backup 的工具映射概念，定义独立的软件计划、WinGet 检测、安装状态与可取消任务。迁移前审查旧清单许可和隐私字段；不直接复制个人电脑的工具清单。
3. **系统功能与修复**：将 DISM 可选功能、Store/WinGet 引导、网络和电源配置逐项建模，明确每个动作可恢复的范围与重启需求。
4. **扩展上游功能**：每次新增一个可独立验收的动作类型；绑定固定上游版本，验证权限、冲突、来源与卸载/撤销语义。组件删除和安全服务关闭不纳入默认方案。
5. **发行体验**：Windows 签名和标准用户/UAC 账户边界，macOS 签名/公证与应用包，Linux 打包。跨平台预览不代表所有平台都有 Windows 执行能力。
6. **档案长期兼容**：清单版本迁移、配置差异、多个恢复点之间的顺序和外部变更冲突提示。升级时不静默替换用户的选择。
