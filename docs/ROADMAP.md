# 后续集成路线

本文件保留原定集成方向并记录0.10的推进状态。未实现项目不会出现在 GUI 中冒充可用开关。

0.8已提供234个固定上游WinGet软件标识、63个Cargo/uv/Pip/NPM/VS Code任务、7个DISM功能、4个系统维护和4个存储任务，以及58个注册表设置选择和16个独立电源取值；混合组合、SetupProfile/Mac清单审核导入、v3档案、电源原值恢复及旧v1/v2兼容已接入同一工作区。存储分析/按介质优化及NTFS/ReFS通知策略只读检查已接入，TRIM策略修改与恢复仍待实现。Mac端六类、Windows端五类本机清单采集与版本备份、保存/载入及可信任务审核已接入。Mac原生配置使用Homebrew Bundle安装及独立检查所选formula/cask，可导出Brewfile；Windows所选软件可导出WinGet原生JSON。0.9新增Homebrew补齐/滚动/HEAD原生策略与独立渠道核对、macOS/Windows Rust工具链重部署及请求往返，支持stable/beta/nightly/固定版本/按日nightly。mise core 与 uv 已接入 macOS/Windows 重部署；chezmoi继续仅作设计参考，macOS新增受审核Cargo CLI工具重部署；macOS已新增VS Code扩展与NPM全局包独立重部署；dotfiles、设置合并及精确环境还原仍待接入。0.10新增应用内部署网络方案、代理与软件源、原值备份/回读/历史恢复及五种工具原生配置导出；不涉及系统级代理/DNS/VPN配置。界面已有中英文、主题色、状态、帮助及关于。Windows实际执行和系统效果仍待设备验收。以下事项按各自剩余边界推进。

1. **Windows LTSC 验收（待完成）**：分别在 2021/2024 的干净虚拟机测试用户权限、应用、退出、取消、故障中断与恢复，核对每个设置在系统界面的实际效果；保存脱敏证据。
2. **继续迁移原工具的软件配置能力**：现有WinGet/Cargo/uv/Pip/NPM/VS Code计划、检查、可取消执行及逐项导入已实现；仍需处理Scoop、配置文件/虚拟环境备份与恢复及更多经过审核的包、Shell与编辑器设置合并、代理/模型等能力，并独立验证来源、权限、隐私及恢复边界。个人电脑清单须由用户明确选择导入。
3. **系统功能与修复**：将 DISM 可选功能、Store/WinGet 引导、网络及剩余电源配置逐项建模（当前方案AC五组参数与独立恢复已实现），明确每个动作可恢复的范围与重启需求。
4. **扩展上游功能**：每次新增一个可独立验收的动作类型；绑定固定上游版本，验证权限、冲突、来源与卸载/撤销语义。组件删除和安全服务关闭不纳入默认方案。
5. **发行体验**：Windows 签名和标准用户/UAC 账户边界，macOS 签名/公证与应用包，Linux 打包。跨平台预览不代表所有平台都有 Windows 执行能力。
6. **档案长期兼容**：清单版本迁移、配置差异、多个恢复点之间的顺序和外部变更冲突提示。升级时不静默替换用户的选择。
